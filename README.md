# Турнир пекусов

Запуск: node server.cjs, затем http://127.0.0.1:4173. Открытие HTML напрямую больше не поддерживается.

Кнопка «Войти» открывает общий вход для участников и организаторов. При регистрации участник создаёт логин и пароль, после чего может редактировать только свой профиль. Организатор может выдать или сбросить аккаунт ранее добавленному участнику.

Создаются два независимых аккаунта организаторов: `organizer1` и `organizer2`. Их первоначальные пароли находятся в `data/admin-access.txt`. Смена пароля завершает сессии только этого аккаунта. Сессия живёт 8 часов; перезапуск сервера завершает все сессии.

Данные турнира: `data/tournament.json`. Хеши паролей и связи аккаунтов: `data/accounts.json`. Папка `data` не раздаётся сервером и исключена из Git. Не отправляйте её вместе с исходниками. Сохраняйте её резервную копию перед обновлениями.

Все изменения проверяет сервер, данные общие. Страницы проверяют обновления каждые 5 секунд, кроме ввода в форму или открытого окна матча. При конфликте двух админов действие отклоняется и загружается актуальный результат.

Старые заявки из браузерной демки не импортируются автоматически. Регистрация начинается с чистого серверного списка.

Локальный Node.js сервер слушает только 127.0.0.1. Для внешнего запуска нужны подходящий хостинг, HTTPS, CUP_ORIGIN с точным внешним origin и CUP_SECURE_COOKIE=1. Нельзя публиковать одну папку dist: она требует серверного API. Предыдущий static-манифест Sites не описывает этот сервер; публикация пока не настроена.

## Матчи, дружба и режимы
В заявке указывается отдельный код дружбы / Player ID либо HTTPS-ссылка приглашения Clash Royale / Supercell. Данные видны всем в карточке матча. Для старых заявок организатор может заполнить их кнопкой «Дружба». Ссылка открывается пользователем в игре; сайт не проверяет её срок действия.

Все матчи кликабельны, включая ожидающие и проходы без игры. Режим выбирается сервером однократно на серию при начале матча; анимация длится 4 секунды. Режим одинаков для всех зрителей и сохраняется после обновления. До завершения рулетки нельзя отметить обычную победу. Доступные режимы выбираются организатором: драфт / тройной драфт. Выбор карт происходит в игре, а не на сайте. Перед турниром надо сверить наличие режимов в текущем меню дружеских боёв. Официальные описания опубликованы в 2017 и 2019 годах; они подтверждают механику, но не гарантируют актуальное меню.

Победителя каждого боя отмечает организатор. При 2 победах (3 в финале) серия завершается и победитель продвигается. Можно ввести итог вручную, указать техническое поражение, добавить публичное описание. Ручная замена итогового счёта очищает старый журнал боёв, чтобы он не противоречил исправлению.

Тесты: node tests/server.cjs <абсолютная-папка-проекта>. Они запускают отдельный сервер на порту 4174 с временными данными. Проверены дружба, недопустимые ссылки, права, выбор режима, запрет повторной жеребьёвки, ожидание рулетки, турнир из 13 игроков, BO3/BO5 и комментарии. Проверена генерация клиентской разметки без входа. Визуальное браузерное тестирование не проводилось.
